# lumina_editor_api

`lumina_editor_api` is the small contract package between Lumina Studio and its plugins. It depends on the engine packages (`lumina`, `lumina_core`) and the pure-Dart plugin process package (`lumina_plugin_process`), never on the editor app, so plugins can be built without depending on the editor app itself.

## Place in the architecture

The editor, `lumina_ui`, implements the API; plugins consume it. Both depend on `lumina_editor_api`, and `lumina_editor_api` depends only on `lumina`, `lumina_core`, `lumina_plugin_process` (and `shadcn_flutter` for icons and widgets). This keeps the pub dependency graph acyclic: a plugin never has to depend on the editor app. Plugins generated by the New Plugin wizard depend on this package too. See [Editor plugins](../plugins/index.md) for how plugins are discovered, enabled and compiled in.

## Contents of the package

- `lib/src/api_types.dart`: `LuminaEditorPlugin`, `LuminaEditorContext` and every extension type a plugin can register.
- `lib/src/editor_command.dart`: `EditorCommand`, the action behind menu items and toolbar buttons.
- `lib/src/editor_slot_button.dart`, `lib/src/editor_panels.dart`: slot buttons with live state, and opening and observing plugin panels.
- `lib/src/editor_level.dart`: the open level as plugins see it (`EditorLevelAccess`, whose `changes` is a Flutter `Listenable`; `LuminaEditorHostContext`; `EditorAssetPicker`) and the conversions to and from a plugin process's `PluginLevelAccess`.
- `lib/src/editor_theme.dart`: read-only access to the editor's colour theme.
- `lib/src/project_settings_section.dart`: Project Settings pages.
- `lib/src/process/`: the Flutter side of plugin processes: the shell's `PluginProcessChannel` (`PluginProcessChannel.ofLink`, `.detached`), `PluginProcessAdapter`, `pluginIconOf` / `iconDataOf`, and the adapters between `lumina_core`'s pure change types and Flutter's (`asValueListenable()`, `asListenable()`, `asObservable()`, `asChangeSignal()`).
- `lib/testing.dart`: the loopback test host with its Flutter `channel`.

Re-exported unchanged from [lumina_plugin_process](../lumina_plugin_process/index.md), so a plugin keeps importing only `package:lumina_editor_api/lumina_editor_api.dart`: the level snapshot and spec types, `PluginStorage` and `EditorProjectInfo`, `LuminaPluginCrashReporter`, the MCP types and `EditorMcp`, the plugin process API and runtime, and the wire protocol (`lumina_plugin_protocol`).
