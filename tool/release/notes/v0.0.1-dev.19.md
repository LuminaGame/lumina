## What's Changed

### New Features & Improvements

- **New design language (Aurora)**: Lumina Studio has a new look: new colour tokens, the bundled Manrope and JetBrains Mono fonts and a redrawn window chrome. Panels are rounded islands on the window ground, and the Content Browser opens as a drawer.
- **Viewport**: view options, camera and display settings sit in pills over the viewport, with a floating column for the transform tools.
- **Sub-editors**: every asset editor (Static Mesh, Material, Blueprint, Texture, Animation and the others) uses the islands. Each editor's actions now sit at the right end of the tab bar, so the editors get back the height of a toolbar row.
- **Material editor**: a new artboard layout, with the graph in the centre, the preview and details at the sides and the palette in its own island.
- **Plugin API**: plugins can build their panels with the editor's own islands (`EditorIsland`, `EditorIslandHeader`, `EditorIslandTabHeader`, `EditorIslandSectionLabel`, `EditorTreeRowStyle` and related types in `lumina_editor_api`). The islands follow the editor's theme, including theme switches. The PCG and MiniAI plugins use them.
- **New logo**: the Prism L logo on every app icon (Windows, Linux, macOS, the installers and the Store package).
- **Responsiveness**: the engine can run asynchronously, and mesh and texture uploads go to the GPU off the UI thread. Opening levels with many meshes no longer stalls the editor.
- **macOS**: Lumina Engine and Lumina Studio build and run on macOS (arm64) from source. Release packages for macOS follow once Developer ID signing and notarization are set up.

### Bug Fixes

- The viewport's frame no longer waits for the GPU twice and for the image decode on the UI thread. Frames that took two or three vsyncs now take one.
- The GPU waits in the viewport moved off the UI isolate.
- During Play, the viewport's pills and tool column no longer take the clicks meant for the game's own UI.
- Q/W/E/R change the transform tool only in tabs that have a transform gizmo. They no longer change the hidden level's tool from other tabs.
- The viewport's status placeholder fits in small views.
- The Plugins tab waits for plugin discovery to finish before it lists the plugins.
- The editor window reads its state back from the system after maximizing.
- No frame report is sent after the editor is closed.
- A batch import shows its new folders in the Content Browser right away.
- Traversal moves (mantles and vaults) no longer push the character's hands and legs into the obstacle when it is nearer than the move was made for.
- macOS builds exclude the right architectures, and Play Standalone on macOS finds the built game.

### Other Changes

- Filament upgraded to v1.78.1. The editor downloads the `filament-1.78.1-lumina.1` prebuilt at first launch.
- The release notes come from a hand-written notes file when the release has one.
- Test fixes for Windows: retrying temp-project deletes, a window that stays unmaximized in integration tests, and level meshes released before quitting.
