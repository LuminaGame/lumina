# Filament Materials Guide

Complete reference for authoring shaders and materials in Google Filament and Lumina Studio.

---

## 1. Overview & Core Concepts

Filament is a physically-based rendering (PBR) engine. Lumina Studio uses Filament as its underlying 3D graphics core. In Lumina, custom shaders and materials compile down to Filament material packages (`.filamat`) using Filament's material compiler (`matc`).

### Core Concepts

- **Material Definition (`.mat` source)**: A text file describing properties, parameters, raster states, and GLSL code (`material { ... }`, `vertex { ... }`, `fragment { ... }`).
- **Material Package (`.filamat`)**: The compiled binary containing cross-platform GPU shaders (Vulkan SPIR-V, Metal MSL, OpenGL GLSL, WebGL) generated by `matc`.
- **Material Instance**: A runtime instance binding specific parameters and textures to a parent material.
- **Material Model (Shading Model)**: The lighting calculation model used by the surface (Lit, Subsurface, Cloth, Unlit, Specular Glossiness).

### Material Layering Hierarchy

Filament evaluates surface lobes in a strict physical order from outside (top) to inside (bottom):

```
+---------------------------------------+
|              Clear Coat               |  (e.g., car paint polyurethane, lacquer)
+---------------------------------------+
|                 Sheen                 |  (microfiber fuzz, velvet, peach fuzz)
+---------------------------------------+
|             2nd Specular              |  (anisotropic / dual specular)
+---------------------------------------+
|               Specular                |  (primary dielectric/conductor specular reflection)
+---------------------------------------+
|               Diffuse                 |  (subsurface / Lambertian diffuse body color)
+---------------------------------------+
```

## 2. Shading Models

Filament supports five shading models defined in `shadingModel: <model>`:

| Model | Value | Description | Key Properties |
|---|---|---|---|
| **Lit (Standard)** | `lit` (default) | Standard PBR model for non-metals and conductors. | `baseColor`, `roughness`, `metallic`, `reflectance` |
| **Subsurface** | `subsurface` | Translucent organic objects (skin, wax, marble, jade). | `subsurfaceColor`, `subsurfacePower`, `thickness` |
| **Cloth** | `cloth` | Fabrics, velvet, cotton, satin. | `sheenColor`, `sheenRoughness`, `subsurfaceColor` |
| **Unlit** | `unlit` | Emissive, UI, debug, holograms, skyboxes (no lighting). | `baseColor`, `emissive` |
| **Specular Glossiness** | `specularGlossiness` | Legacy workflow. | `baseColor`, `specularColor`, `glossiness` |

## 3. Material Properties & Inputs

In the `fragment { void material(inout MaterialInputs material) { ... } }` block, you write to fields of `material`:

### Standard Lit Model Inputs

| Property | Type | Default | Description |
|---|---|---|---|
| `material.baseColor` | `vec4` | `vec4(1.0)` | Surface diffuse color (dielectrics) or specular reflectance (metals). Alpha is opacity in blended modes. |
| `material.roughness` | `float` | `0.4` | Perceptual surface roughness `[0.0, 1.0]`. 0.0 is mirror-smooth, 1.0 is rough/matte. |
| `material.metallic` | `float` | `0.0` | 0.0 for dielectrics (plastics, wood, stone), 1.0 for conductors (metals). |
| `material.reflectance` | `float` | `0.5` | Specular intensity for non-metals at normal incidence ($f_0$). Default 0.5 = 4% reflectance. |
| `material.ambientOcclusion` | `float` | `1.0` | Precomputed diffuse shadow factor `[0.0, 1.0]`. |
| `material.emissive` | `vec4` | `vec4(0.0)` | Light emitted by the surface. RGB in intensity (or EV100), W is exposure weight. |
| `material.normal` | `vec3` | `vec3(0,0,1)` | Surface normal in tangent space (from normal map). |
| `material.bentNormal` | `vec3` | `vec3(0,0,1)` | Mean unoccluded direction in tangent space for specular occlusion. |

### Clear Coat Layer Inputs (when `clearCoat: true`)

| Property | Type | Default | Description |
|---|---|---|---|
| `material.clearCoat` | `float` | `1.0` | Clear coat layer intensity `[0.0, 1.0]`. |
| `material.clearCoatRoughness`| `float` | `0.0` | Perceptual roughness of the clear coat layer `[0.0, 1.0]`. |
| `material.clearCoatNormal` | `vec3` | `vec3(0,0,1)` | Separate tangent-space normal for the clear coat layer (e.g. orange peel effect). |

### Anisotropy Inputs (when `anisotropy: true`)

| Property | Type | Default | Description |
|---|---|---|---|
| `material.anisotropy` | `float` | `0.0` | Strength and direction of anisotropy `[-1.0, 1.0]`. Positive aligns with tangent, negative with bitangent. |
| `material.anisotropyDirection`| `vec3` | `vec3(1,0,0)`| Direction of the surface fibers/grain in tangent space. |

### Subsurface Model Inputs (`shadingModel: subsurface`)

| Property | Type | Default | Description |
|---|---|---|---|
| `material.subsurfaceColor` | `vec3` | `vec3(1.0)` | Color of scattered light beneath the surface. |
| `material.subsurfacePower` | `float` | `12.24` | Spectral falloff power of the subsurface scattering. |
| `material.thickness` | `float` | `0.5` | Thickness of the object `[0.0, 1.0]` (thinner regions transmit more light). |

### Cloth Model Inputs (`shadingModel: cloth`)

| Property | Type | Default | Description |
|---|---|---|---|
| `material.sheenColor` | `vec3` | `sqrt(baseColor.rgb)` | Specular tint of the fabric microfibers at glancing angles. |
| `material.sheenRoughness` | `float` | `roughness` | Roughness of the sheen reflection lobe. |
| `material.subsurfaceColor` | `vec3` | `vec3(0.0)` | Scattering color through fabric fibers (e.g. sunlight through curtains). |

### Transmission & Refraction Inputs (when `refractionMode != none`)

| Property | Type | Default | Description |
|---|---|---|---|
| `material.transmission` | `float` | `0.0` | Specular transmission factor `[0.0, 1.0]` (1.0 = fully transparent glass). |
| `material.ior` | `float` | `1.5` | Index of Refraction of the medium (glass: 1.5, water: 1.33, diamond: 2.42). |
| `material.absorption` | `vec3` | `vec3(0.0)` | Optical absorption per unit distance inside the medium (Beer-Lambert law). |
| `material.microThickness` | `float` | `0.0` | Thickness of the thin-walled sheet when `refractionType: thin`. |

## 4. Material Definition File Structure

A `.mat` material source has three sections:

```
material {
    name : "MaterialName",
    shadingModel : lit,
    blending : opaque,
    parameters : [
        { type : float4, name : "baseColorFactor" },
        { type : float,  name : "roughnessFactor" },
        { type : sampler2d, name : "albedoMap" },
        { type : sampler2d, name : "normalMap" }
    ],
    requires : [
        uv0, tangents
    ]
}

vertex {
    void materialVertex(inout MaterialVertexInputs material) {
        // Optional custom vertex displacement
    }
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);
        material.baseColor = materialParams.baseColorFactor * texture(materialParams_albedoMap, getUV0());
        material.roughness = materialParams.roughnessFactor;
        material.normal = texture(materialParams_normalMap, getUV0()).xyz * 2.0 - 1.0;
    }
}
```

### Material Configuration Keys

```
material {
    name : string,
    shadingModel : lit | subsurface | cloth | unlit | specularGlossiness,
    blending : opaque | transparent | fade | add | masked | multiply | screen,
    postLightingBlending : transparent | add | multiply | screen,
    culling : none | front | back | frontAndBack,
    colorWrite : bool (default: true),
    depthWrite : bool (default: true),
    depthCulling : bool (default: true),
    doubleSided : bool (default: false),
    maskThreshold : float (default: 0.4),
    shadowMultiplier : bool (default: false),
    translucency : none | default (default: none),
    clearCoatIorChange : bool (default: true),
    specularAntiAliasing : bool (default: false),
    specularAntiAliasingVariance : float (default: 0.15),
    specularAntiAliasingThreshold : float (default: 0.2),
    clearCoat : bool (default: false),
    anisotropy : bool (default: false),
    refractionMode : none | cubemap | screenspace,
    refractionType : solid | thin,
    vertexDomain : object | world | view | device,
    interpolation : smooth | flat
}
```

### Available Parameter Types

- Scalar / Vectors: `float`, `float2`, `float3`, `float4`, `int`, `int2`, `int3`, `int4`, `bool`, `bool2`, `bool3`, `bool4`
- Matrices: `mat3`, `mat4`
- Textures / Samplers: `sampler2d`, `samplerExternal`, `sampler2dArray`, `samplerCubemap`

Samplers support formatting options:
```
{
    type : sampler2d,
    name : "diffuse",
    format : float | int | uint,
    precision : default | low | medium | high,
    multisample : bool
}
```

### Built-in Shader Functions & Variables

Available inside `fragment` and `vertex`:

```glsl
// Coordinates & Normals
vec2 getUV0()                           // Texture coordinates set 0
vec2 getUV1()                           // Texture coordinates set 1
vec4 getColor()                         // Per-vertex color
vec3 getWorldPosition()                 // World space fragment position
vec3 getWorldNormal()                   // World space surface normal
vec3 getWorldTangent()                  // World space tangent vector
vec3 getWorldBitangent()                // World space bitangent vector
vec3 getViewVector()                    // Normalized direction from surface to camera
vec4 getNormalizedViewportCoord()       // Normalized screen coordinates [0..1]

// Frame Time & Environment
float getTime()                         // Time in seconds

// Vertex shader inputs (in materialVertex):
material.worldPosition                  // vec4 world position to displace
material.clipPosition                   // vec4 clip space coordinate
```

## 5. Comprehensive Material Examples

### Example 1: Standard PBR Material (Roughness / Metallic / Normal / AO)

```glsl
material {
    name : "StandardPBR",
    shadingModel : lit,
    parameters : [
        { type : float4,    name : "baseColor" },
        { type : float,     name : "roughness" },
        { type : float,     name : "metallic" },
        { type : float,     name : "reflectance" },
        { type : sampler2d, name : "albedoMap" },
        { type : sampler2d, name : "normalMap" },
        { type : sampler2d, name : "roughnessMetallicMap" },
        { type : sampler2d, name : "aoMap" }
    ],
    requires : [ uv0, tangents ]
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);
        
        vec2 uv = getUV0();
        vec4 albedo = texture(materialParams_albedoMap, uv) * materialParams.baseColor;
        material.baseColor = albedo;
        
        // Green channel = Roughness, Blue channel = Metallic (glTF convention)
        vec4 pbr = texture(materialParams_roughnessMetallicMap, uv);
        material.roughness = pbr.g * materialParams.roughness;
        material.metallic  = pbr.b * materialParams.metallic;
        
        // Unpack tangent-space normal map
        vec3 n = texture(materialParams_normalMap, uv).xyz * 2.0 - 1.0;
        material.normal = normalize(n);
        
        // Ambient Occlusion
        material.ambientOcclusion = texture(materialParams_aoMap, uv).r;
        material.reflectance = materialParams.reflectance;
    }
}
```

### Example 2: Automotive Car Paint with Clear Coat and Flakes

Features a glossy protective clear coat layer over metallic flake base paint:

```glsl
material {
    name : "CarPaint",
    shadingModel : lit,
    clearCoat : true,
    parameters : [
        { type : float3, name : "baseColor" },
        { type : float3, name : "flakeColor" },
        { type : float,  name : "roughness" },
        { type : float,  name : "metallic" },
        { type : float,  name : "clearCoatRoughness" },
        { type : sampler2d, name : "flakeNormalMap" }
    ],
    requires : [ uv0, tangents ]
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);
        
        // Flake sparkling in metallic base layer
        vec3 flakeNormal = texture(materialParams_flakeNormalMap, getUV0() * 16.0).xyz * 2.0 - 1.0;
        float sparkle = clamp(dot(normalize(flakeNormal), getViewVector()), 0.0, 1.0);
        
        material.baseColor.rgb = mix(materialParams.baseColor, materialParams.flakeColor, pow(sparkle, 8.0));
        material.metallic = materialParams.metallic;
        material.roughness = materialParams.roughness;
        
        // Clear Coat Layer
        material.clearCoat = 1.0;
        material.clearCoatRoughness = materialParams.clearCoatRoughness;
        material.clearCoatNormal = vec3(0.0, 0.0, 1.0); // Smooth glass-like finish
    }
}
```

### Example 3: Velvet & Silk Fabric (Cloth Shading Model)

Simulates light backscattering through microfibers using sheen and subsurface:

```glsl
material {
    name : "VelvetFabric",
    shadingModel : cloth,
    parameters : [
        { type : float4, name : "fabricColor" },
        { type : float3, name : "sheenTint" },
        { type : float,  name : "roughness" },
        { type : sampler2d, name : "weaveNormalMap" }
    ],
    requires : [ uv0, tangents ]
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);
        
        material.baseColor = materialParams.fabricColor;
        material.roughness = materialParams.roughness;
        
        // Weave micro-surface normal
        vec3 n = texture(materialParams_weaveNormalMap, getUV0() * 8.0).xyz * 2.0 - 1.0;
        material.normal = normalize(n);
        
        // Sheen highlights glancing angles for a velvety touch
        material.sheenColor = materialParams.sheenTint;
        material.sheenRoughness = 0.6;
        
        // Soft subsurface light bleed through fabric edge
        material.subsurfaceColor = materialParams.fabricColor.rgb * 0.4;
    }
}
```

### Example 4: Translucent Wax / Jade (Subsurface Scattering Model)

```glsl
material {
    name : "JadeStone",
    shadingModel : subsurface,
    parameters : [
        { type : float4, name : "surfaceColor" },
        { type : float3, name : "subsurfaceColor" },
        { type : float,  name : "thickness" },
        { type : float,  name : "roughness" },
        { type : sampler2d, name : "thicknessMap" }
    ],
    requires : [ uv0 ]
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);
        
        material.baseColor = materialParams.surfaceColor;
        material.roughness = materialParams.roughness;
        material.reflectance = 0.5; // Dielectric
        
        // Subsurface scattering properties
        material.subsurfaceColor = materialParams.subsurfaceColor;
        material.subsurfacePower = 8.0;
        float sampledThickness = texture(materialParams_thicknessMap, getUV0()).r;
        material.thickness = sampledThickness * materialParams.thickness;
    }
}
```

### Example 5: Glass / Diamond with Refraction & Dispersion

```glsl
material {
    name : "PhysicalGlass",

    refractionType : solid,

        prepareMaterial(material);

        material.roughness = materialParams.roughness;
        material.metallic = 0.0;
        material.transmission = 1.0;
        material.ior = materialParams.ior; // e.g. 1.52 for crown glass
```

### Example 6: Brushed Metal with Anisotropy

```glsl
material {
    name : "BrushedSteel",
    shadingModel : lit,
    anisotropy : true,
    parameters : [
        { type : float3, name : "baseColor" },
        { type : float,  name : "roughness" },
        { type : float,  name : "anisotropyStrength" },

    ],

}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);
        
        material.baseColor = vec4(materialParams.baseColor, 1.0);
        material.metallic = 1.0; // Conductor
        material.roughness = materialParams.roughness;
        
        material.anisotropy = materialParams.anisotropyStrength;
        // Direction vector from texture:
        vec2 dir = texture(materialParams_brushedDirectionMap, getUV0()).xy * 2.0 - 1.0;
        material.anisotropyDirection = vec3(normalize(dir), 0.0);
    }
}
```

### Example 7: Hologram / Sci-Fi Shield (Unlit with Fresnel & Animation)

```glsl
material {
    name : "SciFiShield",
    shadingModel : unlit,
    blending : add,
    doubleSided : true,
    parameters : [
        { type : float3, name : "glowColor" },
        { type : float,  name : "scanSpeed" },
        { type : float,  name : "fresnelPower" }
    ],
    requires : [ uv0 ]
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);
        
        vec3 v = getViewVector();
        vec3 n = getWorldNormal();
        float fresnel = 1.0 - abs(dot(n, v));
        fresnel = pow(fresnel, materialParams.fresnelPower);
        
        // Moving scanline grid
        float scanline = sin(getUV0().y * 120.0 + getTime() * materialParams.scanSpeed) * 0.5 + 0.5;
        
        vec3 color = materialParams.glowColor * (fresnel * 1.5 + scanline * 0.3);
        material.baseColor = vec4(color, 1.0);
        material.emissive = vec4(color * 2.0, 1.0);
    }
}
```

### Example 8: Vertex Wind Animation (Foliage Swaying)

```glsl
material {
    name : "WindyFoliage",
    shadingModel : cloth,
    doubleSided : true,
    culling : none,
    vertexDomain : object,
    parameters : [
        { type : float4, name : "foliageColor" },
        { type : float,  name : "windStrength" },
        { type : float,  name : "windSpeed" }
    ],
    requires : [ uv0, color ]
}

vertex {
    void materialVertex(inout MaterialVertexInputs material) {
        // Vertex color alpha channel defines wind mask (1 = leaf tip, 0 = branch base)
        float weight = getColor().a;
        float time = getTime() * materialParams.windSpeed;
        
        vec3 displacement;
        displacement.x = sin(time + material.worldPosition.z * 0.1) * materialParams.windStrength * weight;
        displacement.y = cos(time * 0.8 + material.worldPosition.x * 0.1) * materialParams.windStrength * 0.5 * weight;
        displacement.z = sin(time * 1.2) * materialParams.windStrength * 0.2 * weight;
        
        material.worldPosition.xyz += displacement;
    }
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);
        material.baseColor = materialParams.foliageColor;
        material.roughness = 0.5;
        material.subsurfaceColor = materialParams.foliageColor.rgb * 0.6; // Translucency
    }
}
```

## 6. Lumina Studio MCP Material Integration

When interacting with Lumina Studio via MCP:

1. **Inspect Material Source**:
   ```json
   {
       "tool": "get_material_source",
       "parameters": {
           "assetPath": "Materials/M_CarPaint.lmas"
       }
   }
   ```

2. **Update & Edit Material Source**:
   ```json
   {
       "tool": "set_material_source",
       "parameters": {
           "assetPath": "Materials/M_CarPaint.lmas",
           "source": "material { name: \"M_CarPaint\", shadingModel: lit, clearCoat: true, ... } fragment { ... }"
       }
   }
   ```

3. **Compile Material to Filament Package**:
   ```json
   {
       "tool": "compile_material",
       "parameters": {
           "assetPath": "Materials/M_CarPaint.lmas"
       }
   }
   ```

4. **Validate Compilation Issues**:
   ```json
   {
       "tool": "get_material_issues",
       "parameters": {
           "assetPath": "Materials/M_CarPaint.lmas"
       }
   }
   ```
